部署位置：`/home/nicholas/data/bybit-backtest/web`。网页后端只监听服务器的 `127.0.0.1:18080`，由 Tailscale Serve 提供 tailnet 内的 HTTPS。应用对每个请求核对 `Tailscale-User-Login`，只接受 `nicholaswang180@gmail.com`。不使用 Bybit API 密钥，也不写入任何交易所账户。

## 功能

Top20 USDT 现货交易对的采集状态、历史范围、数据新鲜度、缺口和 OHLC 质量；可选历史区间的 K 线行情图和最多 7 天的 CSV 导出；受锁保护的手动增量同步；屯币宝智能组合（比例平衡/定时平衡）、双均线交叉、RSI 均值回归与海龟现货趋势的参数化回测，以及回测历史查看、JSON 下载和手动删除。回测读取 1 分钟已完结 K 线，收盘信号在下一分钟开盘成交；海龟的止损与加仓使用分钟高低价触发。每笔买卖计入设置的手续费和滑点。策略只做多；最长 5 个日历年，并要求区间 K 线完整。网页不接受上传代码或任意 SQL。

屯币宝支持 2 至 20 个现货币种，默认 BTC/ETH/SOL 权重 50/30/20%，可修改或等权分配。页面显示所选组合共同数据范围并可快捷填入最近 1/7/30/90 天或 1/3/5 年（所有策略均可使用快捷区间）。比例模式每 5 分钟检查，定时模式采用固定 3 个百分点门槛。结果包括同权重买入持有净值曲线、超额收益、回撤、实际交易费用、持仓数量和最近调仓/成交。净值使用估计变现值，期末并未实际平仓。最近成交与调仓各保留最多 50 条；JSON 保存参数、数据指纹、统计与这些明细。完整假设见 [策略说明](../docs/smart-portfolio.md)。

## 新增九种现货策略

内置策略增加多币种动量轮动、布林带均值回归、趋势过滤＋均线回踩、现货网格、低相关组合＋波动率配权、波动收缩突破、MACD＋ADX、Supertrend 和固定预算分批买入。参数定义由 `strategy_catalog.py` 统一提供给表单、API 和计算进程；独立计算在 `strategy_engine.py` 中完成，不需要额外科学计算依赖。

多币策略可选 2 至 20 个币种，页面显示共同数据范围；排名与相关性在每个历史时点使用过去收益重算。单币指标默认 4 小时，多币默认日线。网格按分钟触发且禁止同分钟新买档位立即卖出；分批买入只使用最初存入预算。结果展示策略与持有曲线、现金、成交额、费用、滑点成本及相应策略统计，沿用单币持有对照、历史查看和 JSON 下载。详情见 [九种策略说明](../docs/strategies.md)。新结果引擎版本 5，包含分钟 OHLCV 指纹，认证、锁和运行限制沿用原设置。

## 海龟现货趋势

内置策略选择“海龟 · 现货趋势”。默认 UTC 日线 55/20 突破与退出、20 周期 ATR、1N 单位风险 1%、2N 止损、0.5N 加仓、最多 4 单位，支持 Top20 单币和可选持有对照。参数周期以信号 K 线根数计算，可选 1 小时、4 小时或日线；与行情图显示周期独立。默认至少需要 56 根完整日线，切换策略时将默认最近 30 天改为最近 1 年。

海龟使用收盘确认、下一分钟开盘入场与通道退出，分钟高低价判断止损与加仓；同分钟已有止损优先，每分钟最多加仓一次，抬高后的止损采用保守触发规则。预热在区间内完成，保留现金、不加杠杆，单笔受现金与最低成交额约束。结果新增突破、加仓、止损/通道退出、现金、持仓单位、止损价、累计成交额和模拟滑点成本。规则和与原版的差异见 [海龟说明](../docs/turtle.md)。海龟计算位于 `turtle_strategy.py`，结果引擎版本 4，已有版本 2/3 的策略结果不改写。

## 热门 Top20 收益相关性

从顶部导航打开 `/correlation`。页面读取已发布固定排名快照，按最近24小时 USDT 现货报价币成交额排名并排除稳定币，提供30/90天小时对数收益相关性。可切换对照币、点击热力图选择币对，比较 Pearson、Spearman、同涨同跌比例、滚动30天范围和累计价格收益。上市较晚的币种历史不足项为 NA；XAUT 黄金代币有单独提示。最低关联列表可排除 XAUT。

数据目录由 `BYBIT_WEB_RESEARCH` 配置，默认 `research/top20-current/`（相对工程根目录），其中 `analysis.json` 是必需文件，下载文件见 `web/correlation_data.py` 固定白名单。快照由 `research/build_correlation.py` 从本地分钟库计算，运行方式：`PYTHONPATH=web python research/build_correlation.py --db bybit_spot_1m.sqlite3 --out research/top20-next`；24 小时成交额取自 Bybit 公共 tickers 接口，可用 `--turnover-json` 离线提供。发布时应先在新目录完成文件及校验，再通过原子替换 `top20-current` 符号链接切换整套快照。数据、SQLite 和导出包不提交到 Git；服务无需额外科学计算依赖或 Bybit 密钥。未发布数据时页面提示不可用，API 返回503。

新页面、API、静态资源及所有下载均沿用本人 Tailscale 身份校验；不提供任意文件路径、SQL 或在线脚本执行。分析读取预计算结果，不占用回测计算锁；相关性数据与分钟回测数据分开存储，不自动拉取新的热度排名。

## 多年回测

单次最长 5 个日历年，闰年按实际日期计算（2 月 29 日的五年边界取 2 月 28 日）。最短 30 分钟。前后端及独立计算进程采用同一上限；开始和结束时间按整分钟对齐。快捷区间只填入已有共同数据范围，若不足所选年数会明确提示，手动填写不会自动缩短。

支持长区间需要数据库已有完整数据；此更新不增加采集目标年数。当前采集目标以 Bybit 现货 1 分钟历史可达的最早日期为准，上市较晚的币种在上市前没有数据。数据不足时拒绝回测，不补旧价。

所有策略和单币对照均按分钟流式读取只读事务快照，均线仅保留周期窗口，RSI 保留递推状态。统计覆盖全部分钟，净值图最多抽样 501 点；单币策略成交明细最近 30 条，屯币宝成交/调仓最近 50 条。回测进程上限为 540 CPU 秒、768 MiB 地址空间（Linux）、600 秒实际运行时间，跨进程锁仍限制同时一个计算。页面自动等待最多约 10 分半，可稍后在历史记录查看。超出运行时限提示缩小区间或降低调仓频率。单币对照为只读同步请求，保留 65 秒时限。行情图的 31 天查询和 CSV 的 7 天导出上限独立于回测上限。

## 单币现货持有对照

完成回测或在历史记录中点击“查看”，在结果页“单币现货持有对照（可选）”选择当前 Top20 中的任一币种，无需重跑策略。单币可以在原组合之外。选择“不比较”移除单币曲线。

对照用全部初始资金在原区间首根开盘买入，期间持续持有，手续费、滑点和期末估值沿用原回测口径。展示单币收益、期末净值、最大回撤、策略超额收益（百分点）及期末净值差。屯币宝原有同权重组合买入持有对照保留，曲线分别为绿色策略、黄色组合持有、紫色单币持有。

对照通过只读 `GET /api/backtests/<id>/benchmark?inst=BTCUSDT` 计算，不改写原历史结果。它与策略回测共享并发锁，在同样受限的独立进程中运行。未完成的任务不能比较；币种白名单、身份和完整分钟数据验证同样生效。所选币在该区间尚未上市或缺少数据时提示失败，不缩短区间、不填补价格。

“下载含单币对照的 JSON”包含原参数和结果、当前对照、比较差值、计算时间及单币数据指纹。原“下载 JSON 结果与参数”仍只下载保存的策略结果。对照读取计算时的数据库，只读查询内保持快照；历史策略及新对照各有独立数据指纹，后续数据修复可能改变重新计算的对照。旧引擎版本 2 的单币策略采用手续费与滑点相加的期末成本近似，对照沿用它；屯币宝版本 3 使用复合扣费。最大回撤逐分钟计算，曲线最多抽样 501 点。

服务器上可用以下命令检查：

```bash
tailscale serve status
ss -lntp | grep 18080
curl -s http://127.0.0.1:18080/healthz
crontab -l
python3 /home/nicholas/data/bybit-backtest/collector.py status
```

Web 服务由用户 crontab 中的 `flock` 守护项启动：进程退出后下一分钟会重启。`web.log` 位于本目录。网页查询使用只读数据库连接；手动同步通过固定采集命令写入。回测在受 CPU、内存和运行时间限制的独立进程中完成，跨进程锁限制同时运行一个任务。最多保存 200 个回测文件；服务重启后中断的任务会标为失败，可重新提交。每日备份由 `backup_db.py` 使用 SQLite Online Backup API 完成并验证完整性，默认保留最近 14 份，不要在采集写入期间只复制单个 `.sqlite3` 文件。

安全边界：Tailscale Serve 仅在 tailnet 内提供访问；应用进程绑定 loopback，并在应用层检查身份。所有写操作需要 CSRF 令牌，有 Origin 时要求匹配固定站点。接口限制查询区间和输入参数，文件名由服务生成，不接受用户路径。若改变绑定地址、启用 Funnel、修改 Tailscale 用户或共享此设备，应重新验证访问权限。`/healthz` 不含数据，仅供健康检查。

## Top20 回测范围

名单统一在 `market_config.py`：BTC、ETH、SOL、AAVE、HYPE、ENA、XRP、LINK、ASTER、PIEVERSE、NEAR、MNT、WLD、XAUT、BNB、VVV、GRAM、LIT、ZRO、HOODX（均为 USDT 现货）。前端选项来自服务端模板；API、分钟采集和受限计算进程使用同一配置。历史对照币种（DOGE、PEPE、SUI、ADA、AVAX、TRUMP、UNI、FIL、ATOM、SHIB）仍可用于单币持有对照，但不出现在 Top20 选币列表。

所有策略、单币持有对照和行情查询均支持这些币种。新增币种可用区间取决于分钟回溯进度，最长5年的参数上限不代表已有5年数据。最多20币的组合仍受统一运行时间和内存限制，不补缺失价格。修改名单时必须先取得相应真实分钟数据，并与相关性快照更新同步发布。

## 操作台模块路径

作为 Bybit 个人交易操作台的“现货行情与回测”模块部署时，由 Tailscale Serve 将 `/spot-lab` 转发到本服务，并给 gunicorn 设置 `BYBIT_WEB_PREFIX=/spot-lab`。`app.py` 使用 `APPLICATION_ROOT` 与前缀中间件剥离路径，因此页面、静态资源和 API 的内部 URL 保持原样。根目录部署（本地测试）不设置该变量即可。
