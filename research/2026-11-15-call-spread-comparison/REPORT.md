## 2. 可执行价格、期限与同预算口径

- 本次只有 2026-11-27、12-04、12-25 三个到期日处于 **10–40 天**区间，均 08:00 UTC 到期，剩余约 11.90、18.90、39.90 天。12-25 此时已进入 40 天以内；这是与早上报告的 40.1 天差异的原因。
- 所有腿都是 Trading、Call、USDT 报价与结算，同标的、同到期、等数量。BTC 最小量 / 步长为 0.01 / 0.01；ETH 为 0.1 / 0.1。BTC tick=5 USDT，ETH tick=0.1 USDT；数量按标的币计，不乘传统美股期权的 100。
- 基础开仓：买腿 **ask + 1 tick**，卖腿 **bid − 1 tick**；平仓：买回短腿 ask + 1 tick，再卖长腿 bid − 1 tick。买卖方向全部用可见对手价，markPrice 不参与成交计算。另做每次开仓每腿 2 tick 的敏感性检查。
- 每笔每腿 taker 假设：`f(p,I,q)=min(0.0003×I, 0.07×p)×q`。沿用原研究保守 7% 上限，不使用临时折扣；不是账户实际费率报价。开、平仓分别计两腿费用。下表9个代表结构的每腿价格均使指数费率项生效；完整29个结构中另有3条买腿触及权利金费率上限，代码均按 min 逐腿计算。
- **每个结构使用相同 25 USDT 理论到期亏损上限**，包括开仓费与 1 tick 滑点，**不包括未来平仓费、交割费、持仓成本、分腿失败和清算损失**。这是研究比较尺度，不是用户已授权风险预算。若映射为净值 0.5%，25 USDT 算术对应净值 5,000 USDT，仍不能推导开仓资金需求。
- 数量 `q=floor_to_step(25 / 每单位理论亏损)`，再按两腿双向顶档数量与单笔最大量向下限制；低于最小量则跳过。**同上限并不强行填满预算**。BTC 不能为贴近 25 而把 0.01 硬增到 0.02。两个标的都做或两种策略同时做会叠加风险；本表各行是互斥备选，不能直接组合。
- 两腿双边报价需正向且未交叉，价差 `(ask-bid)/mid ≤5%`、双向顶档量均足够。这里只验证顶档可见数量，未采集 L2 深度、队列位置或可成交持续时间。单份 ticker 的响应 `time` 不是每条报价的最后更新时间；请求很新仍可能包含旧盘口。因此本快照只能筛候选，不能凭它认定成交。

|---|---|---|
| 买入腿 | 高行权价 Kh | 低行权价 Kl |

## 3. 成本过滤与可复核候选

以下门槛是本次探索研究的显式假设，尚未验证经济最优性。未来实验应先冻结，再取新的独立盘口：

- 信用：短腿 Delta 0.15–0.30、长腿 Delta 0.05–0.20，短腿行权价高于当前期权指数，价差宽度 / 指数 2%–5%。借记：长腿 Delta 0.50–0.65、短腿 Delta 0.25–0.40，宽度 / 指数 3%–8%。Delta 仅为选腿描述，不等于真实盈利概率。
- 两类都要求：理论最大盈利 / 理论最大亏损 **≥0.25**；开仓相对 mid 的摩擦 **≤最大盈利 15%**；同快照按反方向平仓的总损失（四次腿费用与滑点）**≤理论亏损 15% 且 ≤最大盈利 25%**。mid 只用于摩擦比较，不用于成交。

## 4. 顺序执行、回滚与保证金

### 买保护腿仍会暂时超出净风险预算

两种结构均**先买长 Call，再卖短 Call**，入场不先裸卖。看涨借记价差的第一腿是一张低行权价单独 Call，其现金支出可明显大于净借记：BTC 12-25 为 41.30、ETH 11-27 为 47.73，而组合理论亏损分别仅 23.49、22.20。如果长腿买入后暴跌、短腿卖不出，长腿可能损失接近整笔权利金，理论组合预算不再约束这条未完成路径。

下一轮方案须同时保留两条研究限制：组合理论亏损 ≤25；**第一腿支付现金 ≤100 USDT**（只是演示上限，沿用原实验的临时长腿约束），外加未知的实际保证金条件。达到这两个研究门槛也不能批准真实交易。

### 仅为下一轮准备的状态流程

1. 决策快照只产生意图，不在同一快照“成交”。第一腿限价为意图 ask 上浮 2%、按 tick 向上取整；最早在之后源响应时间更晚且接收正常的新盘口，按 ask+tick 模拟，且不得超限、顶档量足够。不凭 mark 或碰价推定排队成交。
2. 第一腿完成后，再产生卖腿意图；卖价下限为最初决策 bid 下浮 2%、按 tick 向下取整。仍需下一份新盘口；在真正卖出前，用长腿已付成本和新卖价重新计算预算、费用、盈亏比，失效就取消卖腿并回滚长腿。两个时间点期间的价格风险不能忽略。
3. 任一意图 30 分钟到期。长腿未成则结束；长腿已成但短腿失败则撤短腿，再生成卖出长腿回滚意图，下一份新盘口按 bid−tick 和费用记账。若无有效盘口，标记“未解决长腿”，不能假设已退出或记零损益。部分成交只按已匹配数量视作价差，剩余长腿单列；任何未覆盖的短腿数量禁止新增。
4. 平仓先买回短 Call，再卖长 Call；短腿未回补前不得去掉保护长腿。每一步都需独立后续盘口。突然上跳时买回短腿所需现金和保证金释放时点可能造成执行障碍；不能先卖保护腿筹钱。
5. 所有回滚、放弃、缺价、漏采和尾部持仓都进入总账，包括未组成价差的损失。止损只触发意图，30 分钟超时也不是能成交的承诺。报价中断、应用退出、限价不成、滑点越界或费用上升均可能使已完成价差的理论到期边界不适用于实际路径。

### Bybit 保证金不能等同理论最大亏损

本研究**没有账户资料、保证金试算、真实组合订单确认或清算路径验证**。两类价差都包含卖出 Call。Cross Margin 可能按卖腿风险规则占用较多保证金，不能默认两腿一比一抵销；Portfolio Margin 可按整个组合压力情景提供抵扣，但仍受风控参数、其他持仓、抵押品折扣、模式/资格和价格路径影响。买方净支付有限并不免除组合中短腿的保证金风险。跨保证金还可能牵连账户其他仓位。

Bybit 官方价差比较文章的历史示例中，同一熊市 Put 价差的 Cross / Portfolio 初始保证金为 2,315 / 521.58 USDT，总占用为 2,795 / 1,001.58 USDT；这些数字只是机制示例，**不能换算成本次 Call 组合的资金要求**。真实交易前必须另获授权，按实时账户模式核实开仓、分腿、回滚、回补时的可用保证金和清算缓冲。当前生产执行器也未在本研究中验证可用，不能直接启用。

## 5. 不成立或必须跳过的条件

| 条件 | 信用价差 | 借记价差 |
|---|---|---|
| 方向假设失效 | 跌势转为快速反弹、跳空上行，短腿被突破 | 假突破、均线信号滞后、上涨不足或转跌 |
| 波动与时间 | IV 上升可能扩大回补成本；收时间价值不保证正期望 | 时间价值流失或 IV 回落可使方向看对仍亏 |
| 价格不够好 | 费用后净收≤0，盈亏比不足，反向摩擦过高 | 净借记≤0 或≥宽度总额，所需涨幅过大，摩擦过高 |
| 数量/期限不合格 | 任一腿缺价、价差>5%、数量不足、超预算、到期不在10–40天即跳过 | 同左；不能用极远虚值或≤3天到期凑低成本 |
| 无独立执行能力或保证金未知 | 纸面可观察，但不得变成真实开仓 | 同左，即使净借记看起来很小 |
| 统计依据不足 | 高胜率、低Delta、单份高IV都不足以成立 | 好盈亏比和一次上涨都不足以成立 |

BTC 与 ETH 风险高度相关，分散到两个币不等于风险减半；信用结构与原看跌借记都偏空，也不能当成互相对冲。两个 Call 结构分属不同市场状态，直接拿不同日期的收益大小判定谁更好存在状态选择偏差。

## 6. 下一轮纸面验证草案——未启用

优先次序：**等待转强后观察借记；信用只有新报价通过全部过滤且仍处于弱势才观察**。本次拒绝信用结构不能靠下调盈亏比门槛“修复”。未来需要先在新独立目录固定协议、选择器与 SHA-256，之后采集的数据才计入；本报告当前快照不作为前向入场价，也不自动接入原 run-v1。

| 项目 | 拟固定规则 |
|---|---|
| 期限与选择 | 10–40天，在全部条件合格结构中先选 DTE 最接近21天；同差距选短期限，再按第3节Delta排序。每标的每状态最多一组，不加仓、不重入；当轮 BTC/ETH 合计理论预算 ≤25，确定性先 BTC 后 ETH 分配余量，余量不足最小量则跳过。单行表的25上限只是比较，不代表当轮可花50。 |
| 信号 | 第1节完成K线规则。首轮只固定一个候选状态的观察，不在同标的同时开相反价差。 |
| 成本与执行 | 第2–4节逐腿买ask/卖bid+滑点、独立下一快照、2tick预算检查、现金上限100、失败回滚；模拟不等于真实成交。 |
| 观察节奏 | 经用户另外明确启用后才每15分钟采公开行情；意图与成交至少隔一份新有效快照。每条腿同时记录响应时间、接收时间、原始响应哈希；请求/接收或响应滞后>30秒拒绝。当次 ticker 无逐腿更新时间，需明确保留这一限制。 |
| 信用退出 | 以真实纸面完成的净收入C为基数，可成交净P&L ≥0.5C止盈、≤−C止损；不是以25为止损阈值。 |
| 借记退出 | 以真实纸面净借记D为基数，可成交净P&L ≥0.5D止盈、≤−0.5D止损。若结构潜在盈利不足0.5D，入场即跳过。 |
| 共用退出 | 信号不再满足、持有72小时、距到期≤24小时，任何一个触发退出意图。平仓按下一新盘口先短后长，不能假定阈值价退出。 |
| 估值与缺口 | 长腿可卖bid−tick减短腿可买ask+tick，再扣未来两腿平仓费。缺价即未知；间隔>30分钟记录缺口，不插值推造止损成交。 |
| 实验终点 | 有限5天；无信号则报告零成交，不能为产生成交放松规则；有持仓到终点则执行退出/明确未解决头寸，不默默删掉。 |
| 最终报告 | 全部逐腿现金流与费用、完成和失败次数、预算利用、执行延迟、净P&L、有效估值下最大浮亏/回撤、缺口、尾部持仓与2tick敏感性。禁止只挑成功组成的价差。 |

理论比较预算一致，退出规则按两种结构不同的现金流尺度设置，因此不能用各一笔的收益认定策略优劣。可另列同72小时退出的配对描述，但状态不同、未成交或无信号都必须保留。5天或几笔成交只验证数据与执行账本；即使为正也不能证明可持续盈利。若以后要研究期望收益，需覆盖上涨、下跌、震荡与跳价的独立执行样本，同时处理实际保证金占用、清算及机会成本；当前没有这些证据。
